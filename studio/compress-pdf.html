Frequently Asked Questions

Why is my PDF still large after compressing it?

Most of a PDF's size comes from images, so a file with few images, or images that are already small, won't shrink much, and the result message tells you when the size couldn't be reduced. Try a stronger level such as Aggressive, turn on Convert to Grayscale, or switch to Photon if the file is a scan.

How much does each compression level reduce image quality?

With Condense, Light keeps images at 90% JPEG quality and 150 DPI, Balanced uses 75% and 96 DPI, Aggressive uses 50% and 72 DPI, and Extreme uses 30% and 60 DPI. Balanced is the default and reads fine on screen; Light is the safer choice for anything that will be printed.

Will I still be able to select and search text after compression?

With Condense, yes: it recompresses images, subsets fonts, and cleans up the file structure without touching the text layer, so selection, search, and links keep working. Photon renders every page to a JPEG, which permanently removes selectable text and hyperlinks.

Does compressing remove metadata from my PDF?

It depends on the level. Light keeps the document info fields, Balanced, Aggressive, and Extreme strip them, and the two strongest levels also remove XMP metadata. You can override this either way with the Remove metadata checkbox under Custom Settings.

Can I compress a scanned PDF?

Scanned PDFs are full-page images, so they respond well to compression. Start with Condense at Balanced or Aggressive, which downsamples the scans in place, and use Photon only if you need a smaller result and can accept losing any OCR text layer the scan may have.

What do the Custom Settings do?

They override the preset for the Condense algorithm: Output Quality (1 to 100) sets JPEG quality, Resize Images To sets the target DPI, and Only Process Above leaves images already below that DPI alone. Checkboxes let you remove metadata, subset fonts, and drop embedded thumbnails.

Can I compress a PDF to a specific size like 1 MB?

There's no target size box on this page, so step through the levels and check the size in the result message until the file fits. For common limits there are dedicated pages with settings chosen for that ceiling, such as Compress PDF to 1MB.

Is my PDF uploaded to a server for compression?

No. Condense runs a PyMuPDF engine compiled to WebAssembly and Photon uses the browser's own page renderer, so everything happens on your device. You can compress one file or a whole batch, which comes back as compressed-pdfs.zip, and none of them leave your computer.
